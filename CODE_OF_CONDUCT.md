# Code of conduct

This is a small project. The standard here is the one you would want applied to you.

**Be decent.** Disagree with the work, not the person. Harassment, personal attacks, and hostility toward anyone for who they are are not tolerated in issues, pull requests, commits, or anywhere else this project happens.

**Argue with evidence.** This repository already runs on measurements rather than opinions, and the same applies to how people talk to each other. "This is wrong because X, and here is the number" is welcome from anyone. "This is obviously bad" is not an argument.

**Assume the other person read the docs and still got it wrong.** They probably did, and that usually means a document is unclear rather than that they are careless. Fixing the document is a contribution.

**If something goes wrong, say so.** Report it privately to the maintainer through [GitHub](https://github.com/HarkiratMangat), or open an issue if you would rather it be public. Reports are handled by the maintainer, who will act on them, up to and including blocking someone from the repository. There is no committee and no formal process; there is one person, and he will read it.

---

This is deliberately shorter than the [Contributor Covenant](https://www.contributor-covenant.org/), which is the usual choice and a good one for a project with more than one maintainer. If this project ever has a community rather than a contributor or two, that is what it should adopt — a four-line code of conduct works because there is currently nobody to arbitrate between.
