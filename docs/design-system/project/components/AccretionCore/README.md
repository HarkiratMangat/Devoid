The app's loading state: a black hole is an absence ringed by light, which is what this product makes. A tilted conic disk (`star`, `ruby`, a gap, `cyan`, `star`) orbits a `singularity` core with a hairline `mark` ring. The two load-bearing colours are the two colours of an accretion disk, so the loader is the product's two ideas orbiting the thing being removed.

- Use it on tiles, in the drawer and for the boot state. Never on the stage: lensing there would show you something you are not going to get.
- No glow. A drop-shadow around the disk is the generated-UI tell the detector rejects; the geometry carries it.
- Size is `--core-size`. With reduced motion the disk stops and sits at 55% opacity: a still disk with a ringed core still reads as working.
- The state pip is the same object at 10px, always on screen in the chrome: idle `graphite-3`, working `cyan` (breathing in opacity, never scale), blocked `ruby`. It is not colour alone, so give it an aria-label carrying the word.
