What this setting is about to destroy: background pixels removed, artwork pixels lost, artwork surviving. The engine already computes these. An app about destruction that never says what it destroyed is hiding its own subject.

- The first figure uses the `figure` style (34px). Loss is `ruby-ink`, safe is `ok`, and the bar's removed segment carries the hatch so a proportion survives greyscale.
- A BLANK ledger is the "not checked" state. It is louder than a chip, because an absence where numbers belong looks like what it is. Write "Not checked" in `amber`; never fill it with a figure that did not run.
- The consumer supplies the three counts from the engine's own report. Never estimate them.
