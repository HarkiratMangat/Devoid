The lighting toggle: a miniature of the wipe, with the same dashed `cyan` cut line. Collapsed is the void; emitting is a white hole, giving light back instead of taking it. It is the bright ground you need to check dark artwork, so the metaphor costs nothing.

- The control is a SEAM, not a dot, a rocker or a knob. State is the position of the cut and a travelling hot rim, so it is never colour alone, and a handle would promise dragging where this clicks.
- Set the state as the `emitting` class (or `data-theme`) on the root before first paint to avoid a flash.
- The move uses `--ease-collapse` (expo-out: it decelerates and never overshoots). With reduced motion the overshoot is neutralised and the transition dropped.
- Pair it with the word COLLAPSED or EMITTING in `lamp-word`.
