The product's thesis as a gesture: two versions of the same asset, one seam, dragged. The seam is the cut line, dashed `cyan` with a blade handle, so the metaphor and the control are the same object. It replaces the abstract question "is this region design or background?" with both answers side by side.

- Left of the seam is the original, right of it is the cut, on ONE ground that spans both halves. Never change the ground at the comparison line.
- Judge the edge here and nowhere else. Lensing, dimming and tints never touch the wipe.
- The consumer supplies the two renders, sized alike. Drag sets `--seam` (a percentage of the element).
- Use the Matte control to check the cut on white, black and chroma as well as the checker; each catches what the others hide.
