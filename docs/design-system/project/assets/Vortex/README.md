The vortex: the accretion disk as a mark, hot blue on the inner edge and warm red-orange on the outer, the same two colours as `cyan` and `ruby`. It is the O of the wordmark, shown alone. These are raster source art; the app draws its own horizon in CSS with no glow.

Each file has two names: the URL name it is stored under here, and the pretty name it carries in the source folder (`DEVOID Logo Assets`). Spaces and capitals are kept in the pretty name, hyphens in the URL name.

| URL name | Pretty name | Notes |
|---|---|---|
| `vortex-navy.png` | DEVOID Vortex Navy.png | The vortex alone on the navy ground. |
| `vortex-transparent.png` | DEVOID Vortex Transparent.png | The vortex alone, transparent. |

The old file names are kept in `DEVOID Logo Assets/Isolated/Legacy Names/`.
