Nebula source art: a magenta and teal deep-sky field, violet-tinted and never neutral black, which is where the UI's `void`, `neb-violet` and `neb-blue` take their cue. The shipped UI uses none of these: it paints one star canvas and two soft blooms, and rejects the tiled grid motif. Use the no-grid files for anything that sits behind the product.

Each file has two names: the URL name it is stored under here, and the pretty name it carries in the source folder (`DEVOID Logo Assets`). Spaces and capitals are kept in the pretty name, hyphens in the URL name.

| URL name | Pretty name | Notes |
|---|---|---|
| `nebula-grid.png` | DEVOID Nebula Grid.png | Wide nebula with a faint grid. |
| `nebula-no-grid.png` | DEVOID Nebula No Grid.png | The same field without the grid. |
| `nebula-no-grid-upscayl1x.png` | DEVOID Nebula No Grid Upscayl1x.png | The no-grid nebula run through Upscayl at 1x. |

The old file names are kept in `DEVOID Logo Assets/Isolated/Legacy Names/`.
