Wide banners for the repository and the README. Warping and lensing belong to banners and the empty table, never to the product's stage, where an edge is judged.

Each file has two names: the URL name it is stored under here, and the pretty name it carries in the source folder (`DEVOID Logo Assets`). Spaces and capitals are kept in the pretty name, hyphens in the URL name.

| URL name | Pretty name | Notes |
|---|---|---|
| `banner-no-warp.png` | DEVOID Banner No Warp.png | The banner with no warp. |
| `banner-warp.png` | DEVOID Banner Warp.png | The banner, warped. |
| `banner-warp-fade.png` | DEVOID Banner Warp Fade.png | Warped, with rounded and faded edges. |
| `banner-warp-vignette.png` | DEVOID Banner Warp Vignette.png | Warped, with a vignette. |

The old file names are kept in `DEVOID Logo Assets/Isolated/Legacy Names/`.
