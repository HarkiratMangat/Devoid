The app icon in two forms. The square is the full-bleed art; the rounded one is the same art in the macOS shape with transparent corners. The `.icns` build files are not stored here.

Each file has two names: the URL name it is stored under here, and the pretty name it carries in the source folder (`DEVOID Logo Assets`). Spaces and capitals are kept in the pretty name, hyphens in the URL name.

| URL name | Pretty name | Notes |
|---|---|---|
| `app-icon-square-1024.jpeg` | DEVOID App Icon Square 1024.jpeg | The full-bleed square, 1024px. |
| `app-icon-rounded-2048.png` | DEVOID App Icon Rounded 2048.png | The same art in the rounded macOS shape, 2048px. |

The old file names are kept in `DEVOID Logo Assets/Isolated/Legacy Names/`.
